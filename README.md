# EmbedKit_AbhishekKanawade

## Name

Abhishek Kanawade

## Description

Implementation of a circular ring buffer (FIFO) for uint8_t data with a fixed capacity of 8 bytes.

## Files

* ringbuf.c : Ring Buffer implementation and demonstration program.

## Build Instructions

```bash
gcc -Wall -std=c99 ringbuf.c -o ringbuf
```

## Run Instructions

```bash
./ringbuf
```
